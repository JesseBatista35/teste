 Como faço para solicitar autorização para uma regra cujo fluxo não é autorizado (p. ex. "Rede não permitida pela regra de negócio ID 000")?
Existem casos em que a linha de regra não está de acordo com os fluxos permitidos, nesse caso, logo abaixo da linha de regra, abre se um campo para justificativa, que servirá de base para análise de autorização por parte da GECMI, portanto apresente argumentos técnicos, se necessário anexe a documentação do produto, serviço, sistema ou ferramenta que justifique a necessidade de exceção.
