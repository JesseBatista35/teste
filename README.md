Procedimentos para obtenção de PKCS#12 

 

Para execução do procedimento de obtenção do PKCS#12 openssl pkcs12 -in INFILE.p12 -out OUTFILE.crt -nokeys é necessária a existência de uma demanda de instalação correspondente. 

Serviços para certificados de ambientes classificados como de “Não Produção” ou sistemas Departamentais; 

Tarefas de mudança para certificados de ambientes classificados como de “Produção”. 

Atentar que alguns ambientes podem sustentar concomitantemente ativos de Produção e Não Produção. Nesse caso, será considerado para todos os efeitos um ambiente de Produção. 

 

Após a definição da demanda de instalação: 

 

Acessar o canal desejado na equipe; 

Aguardar admissão à sala, caso necessário; 

Informar a necessidade para o empregado em atendimento, informando o número da demanda de instalação; 

Aguardar a criação de uma pasta compartilhada no One Drive; 

Obter o arquivo PKCS#12; 

Caso haja instalação imediata, prosseguir para o próximo tópico. 

 

Procedimentos para inserção de senhas 

Acessar o canal desejado na equipe; 

Aguardar admissão à sala, caso necessário; 

Informar a necessidade para o empregado em atendimento; 

Apresentar sua tela e conceder o acesso; 

Observar se a tecla Caps Lock da máquina de destino está desativada; 

Aguardar o empregado realizar a inserção da senha; 

Realizar testes e sair da sala para possibilitar o próximo atendimento. 

 

Os procedimentos para obtenção do PKCS#12 e a respectiva senha podem ser realizados durante o processo de preparo para instalação em Produção.
