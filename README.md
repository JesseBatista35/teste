Para a criação de um novo compartilhamento NFS, é necessário que a solicitação seja registrada por meio do InfraFácil, utilizando o formulário específico para provisionamento desse recurso.

Durante o preenchimento da solicitação, deverão ser informadas todas as informações necessárias para a criação do ambiente, incluindo, mas não se limitando a:
-Nome do NFS;
-Capacidade inicial requerida;
-Relação dos IPs que necessitarão de acesso ao compartilhamento.

Ressaltamos que os IPs informados para permissionamento deverão pertencer à rede 10.188.0.0/16, uma vez que essa é a nova rede habilitada para comunicação com o ambiente de armazenamento.

Após o registro da solicitação contendo todas as informações necessárias, a equipe de armazenamento poderá prosseguir com a análise e o atendimento da demanda.
