Qual pipeline especificamente está apresentando o erro (nome completo/link do pipeline no Azure DevOps);

Qual o repositório/origem correta (Azure DevOps/Git ou ALM) da atualização que motivou a reabertura da demanda, sendo que, caso confirmado ALM, a demanda deverá ser redirecionada à equipe responsável, por não ser suportado pela CESTI.

Diante do exposto, esta solicitação está sendo devolvida como não acatada, aguardando esclarecimento e confirmação dos dados acima para que a análise possa prosseguir.
