É tipo assim: a esteira baixa sempre "a versão mais nova" do Android SDK, em vez de uma versão fixa. Enquanto o Google não mudava qual era "a mais nova", tudo funcionava. Só que o Google lançou uma versão nova do SDK, ela virou automaticamente "a mais nova", e a esteira passou a baixar ela sem ninguém pedir. O problema é que essa versão nova tem umas licenças que o robô que aceita elas automaticamente não está conseguindo aceitar direito — aí o build trava esperando alguém clicar "sim" numa licença, e nunca tem ninguém pra clicar.

Por isso pegou todo mundo ao mesmo tempo, sem ninguém ter mudado nada: não foi vocês que quebraram, foi o Google que trocou a versão "padrão" por baixo, e a esteira do CoE está configurada pra sempre seguir esse padrão em vez de usar uma versão travada.
